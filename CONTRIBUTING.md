# Contributing to Mini SAST

Thank you for your interest. Contributions are welcome.

---

## Development Setup

**Requirements:** Java 21, Maven 3.9+

```bash
git clone https://github.com/SadiqIbrahim01/mini-sast.git
cd mini-sast
mvn clean verify
```

All 150+ tests must pass before submitting a pull request.
